## 项目简介

为 2026 年秋招央国企笔试准备的系统化学习仓库，涵盖三大板块：**计算机基础**、**行测（EPI）**、**申论/写作**。

- 📋 **2121 个知识点**，每个带 `[ ]` 勾选框，学完勾掉
- 🤖 **Claude Code 驱动**，AI 讲解 + 笔记自动沉淀
- 🔄 **每日自动同步**到 GitHub，学习进度可视化

## 学习路线

### 第一阶段：知识扫盲（7 月底 - 8 月中旬）
- 每天 2h 计算机基础 + 1.5h 行测刷题 + 1h 方法论
- 周末资料分析速算 + 数量关系突破

### 第二阶段：专项突破（8 月中旬 - 9 月初）
- 计算机基础二刷 + 行测套题限时
- 申论/写作练习 + 企业特色背诵

### 第三阶段：模拟冲刺（9 月初 - 考前）
- 保持手感 + 错题回顾 + 全真模拟
- 企业特色知识突击
