# 计算机类笔试备考合集

> 一个仓库装两个备考项目：**国家电网计算机类笔试** + **央国企科技岗笔试**
> 面向 2026 年秋招，覆盖计算机类笔试的完整知识体系

---

## 两个项目对比

| 维度 | 计算机基础学习 | 央国企科技岗笔试 |
|------|--------------|----------------|
| 目标 | 国家电网计算机类笔试 | 央国企科技岗笔试 |
| 依据 | 官方 2026 版考试大纲（PDF） | 《央国企科技岗笔试精讲》PDF |
| 内容形式 | 自建笔记（按考纲精编） | PDF 原文 + 网页阅读器 |
| 体量 | 47 个主知识点 / ~350 子知识点 | 1173 页 / 16 大部分 / 141 专题 |
| 阅读方式 | 双击 `.command` 打开笔记阅读器 | 双击 `.command` 打开 PDF 阅读器 |
| 特点 | 带真题、速记口诀、易错陷阱 | 目录导航 + 全文搜索，内容权威详尽 |

---

## 快速开始

> 仅需 macOS + 系统自带 Python3，阅读器**零依赖**，无需安装任何东西。

### 计算机基础学习
双击 `计算机基础学习/打开阅读器.command`（或运行 `python3 reader/server.py`），浏览器自动打开笔记阅读器，8 个模块标签切换、左侧目录、右侧正文。

### 央国企科技岗笔试
双击 `央国企科技岗笔试/打开阅读器.command`（或运行 `python3 reader/server.py`），浏览器自动打开 1173 页 PDF 精讲，带目录导航、全文搜索、缩放、快捷键翻页。
