### 1. 计算机基础学习

国家电网计算机类笔试备考笔记，以官方 2026 版考纲为绝对标准，覆盖 47 个知识点（7 大专业知识模块 + 公共知识）。

- 📖 详细说明见 [计算机基础学习/README.md](计算机基础学习/README.md)
- 🚀 打开方式：双击 `计算机基础学习/打开阅读器.command`，浏览器自动打开笔记阅读器（左侧目录 + 右侧正文）

### 2. 央国企科技岗笔试

- 🚀 打开方式：双击 `央国企科技岗笔试/打开阅读器.command`，浏览器自动打开 PDF 阅读器
