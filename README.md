## 项目简介

## 三大板块概览

### 1. 计算机基础（核心拉分项，占比最高）

```
计算机网络 > 数据结构 = 操作系统 > 数据库 > 组成原理 > 信息新技术
  ⭐⭐⭐⭐⭐       ⭐⭐⭐⭐⭐     ⭐⭐⭐⭐⭐       ⭐⭐⭐⭐      ⭐⭐⭐⭐        ⭐⭐⭐
```

涵盖 6 大模块：计算机网络、数据结构与算法、操作系统、数据库系统、计算机组成原理、信息新技术。

### 2. 行测（EPI）（所有企业必考）

四个模块：言语理解与表达、数量关系、判断推理、资料分析。

目标正确率：言语 80%+、判断 80%+、资料 90%+、数量 60%+。

策略：刷题为主 + 方法论为辅，每天至少 1-2 小时。

### 3. 申论/写作（部分企业考）

电网和部分央企考，运营商/银行基本不考。

策略：掌握框架 + 积累素材，考前集中突击即可。

## 学习路线

### 第一阶段：知识扫盲（7 月底 - 8 月中旬，约 3 周）

| 时间段 | 内容 | 时长 |
|--------|------|------|
| 每天早 | 计算机基础一个模块 | 2h |
| 每天中 | 行测刷题（言语+判断为主） | 1.5h |
| 每天晚 | 行测方法论学习 | 1h |
| 周末 | 资料分析速算 + 数量关系突破 | 半天 |

### 第二阶段：专项突破（8 月中旬 - 9 月初，约 3 周）

- 计算机基础薄弱模块二刷 + 刷真题
- 行测套题限时练习
- 申论/写作练习 + 企业特色知识背诵

### 第三阶段：模拟冲刺（9 月初 - 考前）

- 保持刷题手感 + 错题回顾
- 全真模拟考试
- 企业特色知识突击背诵
