### 各模块覆盖要点

**01 数据结构与算法** — 数据结构三要素与复杂度分析；线性表（顺序 vs 单/双/循环/静态链表）；栈队列（循环队列队空队满、中缀转后缀）；数组压缩存储、KMP 字符串匹配（next/nextval）；树与二叉树（性质、遍历重建、线索二叉树、BST/AVL 旋转、哈夫曼树、堆、并查集）；图（邻接矩阵/邻接表、DFS/BFS、Prim/Kruskal、Dijkstra/Floyd、拓扑排序、关键路径）；查找（顺序/二分/分块、B 树/B+ 树、哈希冲突与 ASL）；八大排序对比；算法设计（分治/动态规划/贪心/回溯/分支限界）。

**02 数据库系统** — DB/DBMS/DBS 概念、三级模式两级映像、E-R 模型；关系代数、三大完整性约束；SQL（DDL/DML/DQL/DCL、聚合、JOIN、子查询）；事务 ACID、并发问题、封锁（S/X）、三级封锁协议、隔离级别、2PL；备份恢复（WAL 日志）；数据库设计六阶段、范式 1NF/2NF/3NF。

**03 计算机网络** — OSI 七层 + TCP/IP 四层；物理层（复用、奈奎斯特/香农）；数据链路层（CRC、滑动窗口、CSMA/CD、交换机与 VLAN）；网络层（IP 分类、子网划分、CIDR、ARP/DHCP、RIP/OSPF/BGP、IPv6/NAT）；传输层（TCP vs UDP、三次握手/四次挥手、拥塞控制）；应用层（DNS、HTTP/HTTPS、FTP、邮件）；网络安全（加密、数字签名与 CA）；无线网络（802.11、CSMA/CA、2G-5G）。

**04 操作系统** — 四大特征、内核态/用户态、中断/异常/系统调用；进程与线程（调度算法、信号量 P/V、经典同步问题、IPC、死锁与银行家算法）；内存管理（分页/分段/段页式、虚拟内存、页面置换 OPT/FIFO/LRU/CLOCK）；文件管理（物理结构、i 节点、硬/软链接、磁盘调度）；设备管理（I/O 控制、缓冲区、SPOOLing）；安全与保护（DAC/MAC/RBAC）。

**05 计算机组成与体系结构** — 冯·诺依曼结构、性能指标（CPI/MIPS）、阿姆达尔定律；机器数表示（原/反/补/移码、溢出判断、IEEE754 浮点、海明码/CRC 校验）；存储系统（Cache 映射/替换/写策略、命中率）；指令系统（寻址方式、CISC vs RISC）；CPU（五级流水线、吞吐率/加速比、硬布线 vs 微程序）；总线与 I/O（DMA、通道）；并行计算（Flynn 分类、多核、GPU）。

**06 软件工程** — 软件生命周期；开发过程（瀑布/增量/螺旋/原型、CMM、甘特图/PERT）；开发方法（结构化 DFD、面向对象 UML、SOLID、敏捷 Scrum/Kanban、DevOps）；需求分析、系统设计（高内聚低耦合、MVC/微服务）；软件测试（黑盒/白盒、回归、缺陷生命周期）；交付维护（CI/CD、四类维护）。

**07 信息新技术** — 人工智能（机器学习监督/无监督/强化、深度学习 CNN/RNN/Transformer、NLP、大模型 GPT/BERT）；物联网（三层架构、协议 MQTT/CoAP/ZigBee/LoRa/NB-IoT）；大数据（5V 特征、预处理、分析、Hadoop/Spark）。⚠️ 只考 AI/物联网/大数据，不考云计算/区块链/5G。

**00 公共与行业知识** — 一般能力（言语理解、信息洞察、思维策略、资料分析）；企业文化·电力与能源战略（核心价值观「人民电业为人民」、「一体四翼」、新型电力系统、特高压）；形势与政策（党的会议精神、政府工作报告、时事）。

## 五、学习流程

1. 打开 `目录.md`，找下一个 `[ ]` 未勾选的知识点
2. 大白话讲解（类比、举例、避免术语）
3. 讲完先总结再提问，确认理解
4. 内容写入对应 `笔记/专业知识/0X-模块.md`
5. 勾选 `目录.md` 对应 `[x]`
6. 更新 `学习进度.md`

**审查规则**：任何产出修改后，必须用 `syllabus-reviewer` agent 对照考纲 PDF 逐条审查，不超纲、不遗漏，直到全部 A 级。
