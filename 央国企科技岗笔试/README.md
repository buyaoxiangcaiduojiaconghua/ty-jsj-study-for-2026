- **零依赖**：纯 Python 标准库 + 浏览器 CDN 的 pdf.js，无需 pip 安装任何东西
- **核心功能**：
  - 📑 侧边栏目录（可折叠手风琴，点击跳转对应页）
  - 🔍 全文搜索（逐页匹配，统计命中数，逐个跳转）
